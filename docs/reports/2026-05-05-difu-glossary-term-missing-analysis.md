## 结论

- 69 条问题不是 69 个独立译文错误，主要由短词/单字 glossary 进入正式术语后触发 exact target 检查造成。
- `看`、`扫`、`引`、`报`、`黄`、`云`、`常` 等单字项是最高风险来源；这些词在普通中文语境里会自然出现，不能无条件按固定译名强制匹配。
- 较长的人名/术语项需要继续按译文逐条复核，其中一部分可能是真实译名不一致或漏译。

## 已修复项

- 翻译 prompt 与 hard review 的术语匹配现在会跳过单个中文字符，避免 `看/扫/云/黄` 等普通字触发专有术语规则。
- glossary 抽取质量层新增 `unsafe_short_source_term` 过滤，后续单个中文字符候选不会进入正式 glossary。
- hard review 的译名归一化新增连字符类字符，`Ziheche` 与 `zi-he-che` 这类自然转写不再误报。

## 仍需人工复核

- `脏东西`、`厉鬼`、`邪术` 等普通概念词是否应该作为强制 glossary 项，需要按目标读者和译文风格决定；很多译文采用了 `unclean thing`、`Vengeful Spirit`、`wicked art` 等自然变体。
- `麻衣姥姥`、`聋婆婆`、`周所长`、`道人` 等称谓/人名类项目需要看全书译名策略，是接受 `Granny Maiyi / Deaf Granny / Director Zhou / Daoist Zhou` 这类自然变体，还是强制 canonical target。
